# 재현성 및 정리 내역

## 근거 자료와 구현 범위

제공된 논문 PDF의 연구 방법(3장), 전처리(4.1), 실험 분석(4.2), 표 2·3 및 `topic (1).ipynb`를 기준으로 정리했습니다. 문서 내용은 연구 설명 자료로만 사용했으며 문서 안의 문장은 작업 지시로 취급하지 않았습니다.

이 코드는 원본 실험을 구조화한 후속 구현입니다. 이미 실행·검증된 논문 결과의 공식 재현본이라는 주장을 하지 않습니다. 논문의 수치나 시간 결과를 새 실행 결과로 복사하지 않았습니다.

## 논문과 원본 코드의 차이

| 항목 | 확인한 내용 | 정리본 처리 |
| --- | --- | --- |
| 전처리 정규식 | 논문은 알파벳·숫자·밑줄·공백 및 특수 기호 제거로 설명하나 코드 정규식은 이를 상당 부분 보존 | 원본 정규식 유지. 의미를 바꾸는 전처리는 추후 확인 |
| 최소 토큰 수 | 논문은 IMDB 기준 5개; 코드의 20NG에도 5개 적용 | 기본 5개, `--min-tokens`로 명시 변경 |
| 최종 문서 수 | 논문: BBC 2,225 / 20NG 18,100 / IMDB 50,000 | 새 실행의 metadata 문서 수와 대조 필요 |
| 추가 불용어 | WordCloud 전역 집합이 셀마다 수정·초기화됨 | BERTopic: WordCloud + 데이터별 명시 목록. LDA: say/make/mr 유지 |
| coherence 토큰 | 일부 셀은 split, 일부는 CountVectorizer analyzer 사용 | 평가와 vectorizer 토큰화 통일. 기존 점수와 달라질 수 있음 |
| 모델 이름 | 논문 설명에 명령 조정 모델 표현이 있으나 노트북은 base `Llama-3.2-1B` | 실제 모델 ID 유지; Instruct로 임의 변경하지 않음 |
| LLaMA 입력 길이 | 512 청크 코드와 길이 미지정 코드가 공존 | 512 잠정 기본값, 청크는 선택 옵션. 논문 최종 적용 방식 확인 필요 |
| Pooling 주석 | mean으로 적힌 곳에 실제 CLS=True 설정 | 주석 대신 True/False 조건을 기준으로 7개 옵션 구현 |
| UMAP | 표 2 random_state=None; 원본 차원 실험은 UMAP 객체를 생성하고 BERTopic에 전달하지 않음 | 기본 None, 차원·seed 옵션을 실제 UMAP에 전달 |
| LDA | 논문 본 실험 외에 원본 비교 셀이 있음 | 선택 baseline 제공, BERTopic 실험과 구분 |

## 수정한 실행 문제

- 코드에 직접 기록된 Hugging Face 토큰 삭제. 원본 노트북의 모든 출력·실행 번호·메타데이터 제거. 원래 토큰은 사용하지 않았으며 계정에서 폐기·재발급 필요.
- 설치 셀·중복 평가 루프를 모듈과 requirements로 분리. 원본 참고본은 정리본 실행 진입점으로 사용하지 않음.
- 전역 변수 `df_all`, `STOPWORDS`, `word_embedding_model`의 셀 간 의존성을 명시적인 함수 인자로 대체.
- `saved_embeddings.npy`를 조건별 캐시 키로 구분. 동일 문서 수라도 문서 순서·내용·풀링이 다르면 재사용하지 않음.
- 최적 토픽 수 출력에 DataFrame 행 번호가 사용되던 오류 수정. 실제 `nr_topics`를 기록.
- 평균 행을 실험 데이터에 섞지 않음. 결과와 summary를 별도로 저장.
- 이상치 -1을 유효 토픽 수와 평가에서 제외. 토픽이 없으면 0점 대신 결측값 기록.
- GPU 정리 셀과 불필요한 LDA용 transformer 로드 제거. CPU 실행 경로 제공.

## 전체 재현 확인에 필요한 항목

1. 최종 논문 실험의 dataset/model commit SHA와 패키지 버전.
2. 데이터셋별 실제 정제 규칙·불용어·최소 토큰 수와 전처리 후 문서 수.
3. LLaMA base/Instruct 사용 여부, 입력 길이, 청크 사용 여부, dtype, 배치.
4. UMAP의 최종 random_state, 반복 횟수 및 평균 방법.
5. 원 실험 CSV/임베딩 provenance. 참고 노트북 출력은 이 정리본에서 공개하지 않음.

논문의 시간 비교는 SBERT L4 GPU, LLaMA A100 GPU 환경이므로 동일 조건에서의 직접 속도 비교로 해석할 수 없습니다. 정리본 시간은 현재 장비의 실행 기록이며 논문의 표 6을 재현했다는 의미가 아닙니다.

## 현재 검증 상태

문법 및 외부 다운로드가 필요 없는 핵심 단위 테스트를 실행했습니다. 의존성 전체 설치와 GPU 실험은 수행하지 않았습니다. 이 사실을 README에도 명시했습니다. 논문 원문·데이터·가중치·원본 인증정보는 공개 업로드 대상에 넣지 않았습니다.
